# 税前利润：原话卡片

## 卡片 1：常规盈利能力税前 170 亿美元

- 原话：我估计我们当前所拥有资产的常规盈利能力大约是税前 170 亿美元、税后 120 亿美元，不包括任何资本利得或损失。
- 来源：2010 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2010-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：定义、核心要义
- 我的理解：税前数字是描述生意本身赚钱能力的起点，税后才是落到股东口袋的结果。

## 卡片 2：喜诗累计税前利润 8.57 亿美元

- 原话：自从我们在1972年以2,500万美元买下喜诗以来，它已累计赚取了8.57亿美元的税前利润。而且尽管业务持续增长，它几乎不需要额外的资本投入。
- 来源：1999 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1999-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：代表案例、总结
- 我的理解：税前利润配合"几乎不需额外资本"，最能刻画一门好生意的盈利能力。

## 卡片 3：喜诗税前利润快过销售额增长

- 原话：利润的增长速度甚至比销售额还快，税前利润从1972年的420万增长到去年的4,240万美元。
- 来源：1991 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1991-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：核心要义、代表案例
- 我的理解：税前口径剥离税率波动，让跨年度的盈利能力变化一目了然。

## 卡片 4：估值看所有者收益而非 GAAP

- 原话：在估值时，无论是投资者买股票还是经理人收购整家企业，应该关注的是所有者收益而非GAAP数字。
- 来源：1986 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1986-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：核心要义、常见误解
- 我的理解：税前利润是通往真实经济收益（所有者收益）的中间步骤，不是终点。

## 卡片 5：递延税款是财政部的"无息贷款"

- 原话：从经济实质来看，这笔负债更像是美国财政部给我们的一笔无息贷款，而且到期日由我们自己说了算。
- 来源：1989 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1989-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：核心要义、常见问题
- 我的理解：税前不等于不在乎税，递延税款本身就是一项可被理性利用的资源。

## 卡片 6：讨厌 EBITDA，折旧是真实成本

- 原话：同样，我们讨厌EBITDA。折旧是最糟糕的支出，甚至可以称之为卑鄙，这是一种反向浮存金。
- 来源：2002 年巴菲特哥伦比亚大学演讲
- 文件：`buffett/interview/ba-fei-te-2002nian-ge-da-shang-xue-yuan-yan-jiang.md`
- 可用于：核心要义、常见误解
- 我的理解：税前利润扣除折旧，EBITDA 假装折旧不存在，这是两者的本质分野。

## 卡片 7：5 美元换 1 美元年税前利润

- 原话：美国企业平均需要再投入约5美元的资本才能增加1美元的年税前利润。
- 来源：1985 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1985-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：核心要义、常见误解
- 我的理解：用税前利润对照资本投入，能区分少量增量资本即可增利的好生意与普通生意。
