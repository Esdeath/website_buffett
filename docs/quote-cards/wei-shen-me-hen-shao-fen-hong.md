# 巴菲特为什么很少分红？：原话卡片

- 原话：我们不支付股息，因为我们认为我们可以把我们保留的每一美元转换成超过一美元的市场价值。

- 我的理解：只要留在公司里的钱能创造超过 1 美元的价值，分红就不是最优选择。

- 原话：我们保存你的钱比我们给你的钱，更有价值。
