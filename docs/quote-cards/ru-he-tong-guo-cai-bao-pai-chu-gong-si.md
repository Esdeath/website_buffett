# 巴菲特如何通过财报判断哪些公司不能买？：原话卡片

下列摘引逐字核对知识库原始材料中文译文，仅截取连续原句；“我的理解”与“边界”均为编者说明。六份来源的适用范围、假设演算及决策树边界见同名来源矩阵。行号以 2026-09-20 核验版本为准。

## 卡片 1：会计辅助商业判断

- 原话：会计只是商业思维的辅助工具，绝不能替代商业思维本身。
- 来源：1986 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1986-ba-fei-te-zhi-gu-dong-xin.md`，第 515 行
- 类型：致股东信
- 可用于：第一关，理解主营业务与重要附注
- 我的理解：数字是判断的起点，仍需解释客户、盈利来源和风险条件。
- 边界：不能解释业务意味着自己缺乏判断基础，不直接证明管理层造假。

## 卡片 2：三项警惕

- 原话一：给投资者三个建议：第一，提防会计可疑的公司。
- 原话二：第二，晦涩难懂的财务附注通常意味着管理层不值得信赖。
- 原话三：第三，要警惕那些热衷于高调宣传利润预测和增长预期的公司。
- 来源：2002 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2002-ba-fei-te-zhi-gu-dong-xin.md`，分别为第 513、517、519 行
- 类型：致股东信
- 可用于：第二关，会计质量与管理层可信度
- 我的理解：异常需要追查披露与经济事实能否对应。
- 边界：三句属于三个段落，不能拼成一个连续原段；保留“通常”“警惕”，不把复杂披露、调整后指标或盈利指引单独视为欺诈证据。检查表为编者整理。

## 卡片 3：到期债务需要现金

- 原话：到了那时候，只有现金才靠得住。
- 来源：2010 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2010-ba-fei-te-zhi-gu-dong-xin.md`，第 589 行
- 类型：致股东信
- 可用于：第三关，融资中断下的履约能力
- 我的理解：盈利不自动等于付款日有可自由动用的现金。
- 边界：“那时候”指公司问题或信用紧缩使债务无法照常再融资；必须与这个前文共同解释。现金缺口计算为编者方法，不是原文公式或负债率红线。

## 卡片 4：所有者收益需要估计

- 原话：我们的所有者收益公式不会得出GAAP那种看似精确实则具有欺骗性的数字，因为(c)必须依靠估计——有时还非常难以估计。
- 来源：1986 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1986-ba-fei-te-zhi-gu-dong-xin.md`，第 495 行；定义见第 493 行
- 类型：致股东信
- 可用于：第四关，估算维持生意所需投入
- 我的理解：需从利润中扣除维持长期竞争地位和产销规模所需的平均资本化支出及必要新增营运资金。
- 边界：(c) 不是当年所有资本开支；从经营现金流出发不可再机械扣一遍已体现的营运资金变动。文章 10＋4－12－1＝1 的例子全部是假设数据，不是巴菲特原有案例。

## 卡片 5：ROE 需要排除杠杆与会计把戏

- 原话：判断一家公司经营管理层绩效好坏的首要标准，应该是看它在不过度使用杠杆、不玩会计把戏的前提下，能否取得高水平的股本回报率，而不是看每股收益是否持续增长。
- 来源：1979 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1979-ba-fei-te-zhi-gu-dong-xin.md`，第 27 行
- 类型：致股东信
- 可用于：第五关，利润增长与资本效率的区别
- 我的理解：多投本钱即可增加利润，仍须看每单位资本获得的成果。
- 边界：原文没有通用 ROE 阈值；回购、减值和负权益会影响可比性。文章新增利润 5／新增资本 100 的 5% 是编者假设粗算，不是精确 ROIC。

## 卡片 6：区分回报不足与资本需求高

- 原话一：最糟糕的企业是那种收入增长迅速、需要巨额资本来推动增长、最后却赚不到什么钱甚至亏钱的企业。
- 原话二：一家需要大幅增加资本投入来推动增长的公司，也完全可能是一笔令人满意的投资。
- 来源：2007 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2007-ba-fei-te-zhi-gu-dong-xin.md`，分别为第 197、189 行；飞安案例见第 191—195 行
- 类型：致股东信
- 可用于：第五关，防止单因重资本而误判
- 我的理解：应结合必要投入与对应回报；飞安需要投入大量资本，仍是好生意。
- 边界：两句为分开摘引，排列顺序按文章论述安排。不能只留第一句而把所有高资本开支企业排除；也不能省略购买价格判断。

## 卡片 7：房地美的风险信号与不确定性

- 原话一：任何时候，大型金融机构开始承诺定期增加收益，你都会遇到麻烦。
- 原话二：我不知道什么时候会发生，我甚至不知道它是否会发生。
- 来源：2010 年金融危机调查委员会专访
- 文件：`buffett/interview/ba-fei-te-2010nian-jin-rong-wei-ji-diao-cha-wei-yuan-hui-zhuan-fang.md`，第 134 行；前后问答见第 132—138 行
- 类型：访谈文章
- 可用于：房地美退出案例
- 我的理解：无法消除的管理层与风险疑虑足以使投资者选择退出，无须先证明未来必然失败。
- 边界：访谈回顾约 2000 年卖出，持仓主要集中房地美；不能写成提前预知 2008 年危机。第 138 行说大量投资垃圾债，但他对具体发行人记忆不确定。案例用于金融机构的管理层与风险判断，不套用工业企业现金流公式。
