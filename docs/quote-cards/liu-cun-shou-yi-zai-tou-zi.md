# 留存收益再投资：原话卡片

## 卡片 1：留存收益是伯克希尔越来越值钱的奥妙

- 原话：股票给投资者带来财富的原因在于，公司的留存收益可以创造新的盈利，还可以用于回购，增加投资者持有的股份。我们伯克希尔从创立的第一天起一直有留存收益。伯克希尔为什么越来越值钱？因为我们不断地留存收益，奥妙就在这里。
- 来源：2020 年接受 CNBC 采访
- 文件：`buffett/interview/ba-fei-te-2020nian-jie-shou-cnbczhuan-fang.md`
- 可用于：中心问题、核心原则
- 我的理解：留存的钱继续赚钱，复利累积，是企业价值增长的主引擎。

## 卡片 2：复利效应在健全投资中发挥作用

- 原话：通常而言，管理良好的工业公司不会将其全部利润都分配给股东……于是，一种复利效应便在健全的工业投资中发挥着作用。经年累月，一家稳健工业企业资产的真实价值，在向股东派发的股息之外，还在以复利的方式不断增长。
- 来源：2019 年巴菲特致股东信（引凯恩斯）
- 文件：`buffett/berkshire/gu-dong-xin/2019-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：起源、复利
- 我的理解：股票跑赢债券的根源，是留存收益带来的复利增长。

## 卡片 3：再投资生产性资产是首要任务

- 原话：在部署留存资金时，我们首先寻求投资于我们已经拥有的众多业务……对生产性经营资产的再投资永远是我们的首要任务。
- 来源：2019 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2019-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：用途优先级、核心原则
- 我的理解：留存资金的第一去向是把现有好生意做得更强，其次才是收购和回购。

## 卡片 4：一美元检验

- 原话：不受限制的收益只有在以下情况下才应当留存：有合理的前景……表明公司每留存一美元，至少能为股东创造一美元的市值。
- 来源：1984 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1984-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：纪律、误解纠正
- 我的理解：留存不是无条件的好，必须经得起一美元检验。

## 卡片 5：看不见的留存收益同样有价值

- 原话：那 28 亿美元未被报告的收益，对我们来说同样有价值。
- 来源：2012 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2012-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：穿透盈余、案例
- 我的理解：被投资公司留存、没分给我的收益，仍在通过回购和再投资为我创造价值。

## 卡片 6：储蓄加复利创造奇迹

- 原话：连小学生都学会了凯恩斯当年称之为“新奇”的道理：把储蓄和复利结合起来，就能创造奇迹。
- 来源：2019 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2019-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：总结、复利
- 我的理解：留存收益再投资的本质，就是把企业版的“储蓄+复利”做到极致。
