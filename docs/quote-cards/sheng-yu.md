# 声誉：原话卡片

## 卡片 1：损失财富可以理解，损失声誉绝不留情

- 原话：折损公司的财富，我可以理解，但折损公司仅剩的声誉，我会毫不留情。
- 来源：1991 年巴菲特出席所罗门听证会发言
- 文件：`buffett/interview/ba-fei-te-1991nian-ba-fei-te-zhi-suo-luo-men-gu-dong-xin.md`
- 可用于：定义、核心要义
- 我的理解：金钱可以重赚，声誉一旦失去几乎无法挽回，这是非对称的底线。

## 卡片 2：声誉一点也不能损失

- 原话：我们已有足够的金钱，能赚更多固然不错，但失去一些也没什么问题。我们不能损失的是声誉，声誉一点也不能有所损失。
- 来源：2007 年与比尔·盖茨对大学生的对话
- 文件：`buffett/interview/ba-fei-te-2007nian-11yue-he-bi-er-gai-ci-da-xue-sheng-dui-hua-shi-lu-jie-mu-fu-hao-mian-dui-mian.md`
- 可用于：核心要义
- 我的理解：声誉是其他一切资产的前提，宁可让金钱出让步也不让它受损。

## 卡片 3：5 分钟就能毁掉声誉

- 原话：我们不能承受声誉上的损失，哪怕只是一点点。因为声誉一旦失去，是无法挽回的。我说过 37 分钟可以毁掉声誉，其实可能更快——5 分钟就够了。
- 来源：2003 年内布拉斯加大学林肯分校领导力课程演讲
- 文件：`buffett/interview/ba-fei-te-2003nian-nei-bu-la-si-jia-da-xue-lin-ken-fen-xiao-ling-dao-li-ke-cheng-yan-jiang.md`
- 可用于：核心要义、误解纠正
- 我的理解：建立要几十年、毁掉只要几分钟，这种非对称决定声誉必须是底线。

## 卡片 4：报章测试

- 原话：我们要确保自己在商业上所做的一切，哪怕是收购、投资等行为，都可以堂堂正正地登上全国性报纸的头版，就算那篇文章是由一位“不友善但聪明”的记者写的，我们也能挺得住。
- 来源：2003 年内布拉斯加大学林肯分校领导力课程演讲
- 文件：`buffett/interview/ba-fei-te-2003nian-nei-bu-la-si-jia-da-xue-lin-ken-fen-xiao-ling-dao-li-ke-cheng-yan-jiang.md`
- 可用于：核心要义、常见问题
- 我的理解：守护声誉的具体方法，就是把每个行为放到报纸头版下检验。

## 卡片 5：可以承受巨额亏损，不能失去一丝一毫声誉

- 原话：当务之急是，我们所有人都要继续不遗余力地维护伯克希尔的声誉……正如我 25 年多来在这些备忘录中反复说的：“我们可以承受亏损——甚至是巨额亏损。但我们不能失去声誉——哪怕是一丝一毫的声誉。”
- 来源：2010 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2010-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：定义、思想演变
- 我的理解：这条原则被正式写进公开致股东信，成为伯克希尔的最高纪律。

## 卡片 6：声誉掌握在你们手中

- 原话：谢谢你们的帮助。伯克希尔的声誉掌握在你们手中。
- 来源：2006 年巴菲特给全体经理人备忘录
- 文件：`buffett/interview/ba-fei-te-2006nian-gei-quan-ti-jing-li-ren-bei-wang-lu.md`
- 可用于：代表案例、常见问题
- 我的理解：声誉是全体员工共同承担的责任，一个人就足以让它受损。

## 卡片 7：声誉走向世界的金字招牌

- 原话：伯克希尔声名远播，我们的声誉已经从美国走向了世界。最近，我们在日本做了投资，其中，伯克希尔的声誉发挥了很大的作用。
- 来源：2024 年伯克希尔股东大会
- 文件：`buffett/shareholders/2024nian-bo-ke-xi-er-gu-dong-da-hui.md`
- 可用于：核心要义、总结
- 我的理解：长期守住声誉后，它会反过来变成别人无法复制的机会与竞争优势。
