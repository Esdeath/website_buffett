# 诚信：原话卡片

## 卡片 1：成功的三样核心品质，诚信最重要

- 原话：要想在这个国家取得真正的成功，最核心的三样品质是：智慧、精力与诚信。
- 来源：2003 年内布拉斯加大学林肯分校领导力课程演讲
- 文件：`buffett/interview/ba-fei-te-2003nian-nei-bu-la-si-jia-da-xue-lin-ken-fen-xiao-ling-dao-li-ke-cheng-yan-jiang.md`
- 可用于：定义、核心要义
- 我的理解：智慧和精力是放大器，诚信决定它们放大的是价值还是破坏。

## 卡片 2：宁要又蠢又懒，不要聪明却不诚实

- 原话：但最重要的是：诚信。如果一个人缺乏诚信，哪怕再聪明、再有干劲，我也不会雇用他。实际上我宁愿雇一个“又蠢又懒”的人，也不要雇一个“聪明但不诚实”的人——因为他可能永远都不会有机会欺骗我们。
- 来源：2003 年内布拉斯加大学林肯分校领导力课程演讲
- 文件：`buffett/interview/ba-fei-te-2003nian-nei-bu-la-si-jia-da-xue-lin-ken-fen-xiao-ling-dao-li-ke-cheng-yan-jiang.md`
- 可用于：核心要义、误解纠正
- 我的理解：没有诚信，聪明和干劲反而是更大的风险。

## 卡片 3：诚信是一种选择

- 原话：所以我说，诚信完全是一种选择。你可能投不出 60 码远的橄榄球，可能跑不出 9.8 秒的百米成绩，但你是否选择成为一个有诚信的人，那完全取决于你自己。
- 来源：2003 年内布拉斯加大学林肯分校领导力课程演讲
- 文件：`buffett/interview/ba-fei-te-2003nian-nei-bu-la-si-jia-da-xue-lin-ken-fen-xiao-ling-dao-li-ke-cheng-yan-jiang.md`
- 可用于：定义、常见问题
- 我的理解：诚信不像天赋由出身决定，而是每天都能重新选择的位置。

## 卡片 4：人品就是最好的保证

- 原话：在这笔交易中，我们既没有要经审计的财务报表，也没有核查房地产产权，更没有要求任何担保。一句话，她的人品就是最好的保证。
- 来源：1993 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1993-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：代表案例、误解纠正
- 我的理解：诚信能替代一整套法律文书，是真实可计价的资产。

## 卡片 5：报章测试

- 原话：在考虑任何商业行为时，员工应该扪心自问，他是否愿意看到一个知情的且持批判态度的记者，立即将其行为刊登在当地报纸的头版上，让他的配偶、子女和朋友们阅读。
- 来源：1991 年巴菲特致所罗门股东信
- 文件：`buffett/interview/ba-fei-te-1991nian-ba-fei-te-zhi-suo-luo-men-gu-dong-xin.md`
- 可用于：核心要义、常见问题
- 我的理解：合法只是底线，能坦然登上报纸头版才是诚信的检验。

## 卡片 6：倚重正直的人

- 原话：分权方面我们开放得难以置信，但我们倚重头脑，倚重有头脑、有干劲和正直的人。他们所作出的决定大多是正确的。
- 来源：2007 年与比尔·盖茨对大学生的对话
- 文件：`buffett/interview/ba-fei-te-2007nian-11yue-he-bi-er-gai-ci-da-xue-sheng-dui-hua-shi-lu-jie-mu-fu-hao-mian-dui-mian.md`
- 可用于：核心要义、企业文化
- 我的理解：诚信让去中心化成为可能，信任替代了层层审批。

## 卡片 7：“每个人都在这么干”不是理由

- 原话：有时候，你的伙伴可能会说：“每个人都在这么干”。如果这是为一项商业活动进行辩解的话，那么这几乎是一个糟糕的理由。如果评估一项跟道德有关的决策时，这绝对是完全无法接受的。
- 来源：2014 年巴菲特给全体经理人备忘录
- 文件：`buffett/interview/ba-fei-te-2014nian-gei-quan-ti-jing-li-ren-bei-wang-lu.md`
- 可用于：代表案例、误解纠正
- 我的理解：诚信要求在群体压力下仍能独立守住底线。
