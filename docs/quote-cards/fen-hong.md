# 分红：原话卡片

## 卡片 1：乐收别人股息，自己一毛不拔

- 原话：伯克希尔有不少股东……希望公司发放现金股息。让他们困惑的是，我们乐意收取伯克希尔所持大多数股票的股息，自己却一毛不拔。那我们就来看看，什么时候分红对股东有意义，什么时候没有意义。
- 来源：2012 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2012-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：中心问题、误解纠正
- 我的理解：分不分红不看惯例，看留下这一美元能否比分掉更值钱。

## 卡片 2：一美元检验

- 原话：不受限制的收益只有在以下情况下才应当留存：有合理的前景……表明公司每留存一美元，至少能为股东创造一美元的市值。
- 来源：1984 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1984-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：核心原则、定义
- 我的理解：这是判断该留还是该分的唯一标准——留下的钱必须变得更值钱。

## 卡片 3：回报高就留，回报低就分

- 原话：如果预期回报率高，你应当希望收益被再投资；如果再投资的回报率可能很低，你应当希望收益被分配给你。
- 来源：1984 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1984-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：核心原则、永续债券类比
- 我的理解：分红决策本质是比较再投资回报率与股东在别处可得的回报。

## 卡片 4：分红政策很少被解释

- 原话：公司通常会向股东报告股息政策，但很少加以解释……我们认为管理层和股东都应当认真思考：在什么情况下应该留存收益，在什么情况下应该分配收益。
- 来源：1984 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1984-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：误解纠正、资本配置
- 我的理解：分红是资本配置决策，不该当成行业惯例不加分析。

## 卡片 5：卖出法/自制股息

- 原话：我们将所有利润留存在公司，同时每人每年卖出手中 3.2% 的股份……这种方法第一年同样能产生 4 万美元的现金收入，而且这笔收入也会逐年增长。
- 来源：2012 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2012-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：案例、常见问题
- 我的理解：股价高于净资产时，自己卖一点股份能制造出比分红更多的现金。

## 卡片 6：收购让股东比分红更富

- 原话：总体来说，我们的记录还算令人满意，这意味着我们的股东比把同样的资金用于回购或分红要富有得多。
- 来源：2012 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2012-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：案例、机会成本
- 我的理解：分红的代价是放弃了再投资和收购可能创造的更大价值。
