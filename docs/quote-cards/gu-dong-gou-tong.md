# 股东沟通：原话卡片

## 卡片 1：把股东当作合伙人

- 原话：查理.芒格和我把股东当作合伙人LP，是真正的所有者，把我们自己当作普通合伙人GP。……我们不愿把伯克希尔的股东看作匿名的来来往往的一群人，而是看作把资金托付给我们的合伙人，而且这可能是他们生命中最重要的投资。
- 来源：1996 年伯克希尔股东手册
- 文件：`buffett/interview/ba-fei-te-1996nian-bo-ke-xi-er-gu-dong-shou-ce.md`
- 可用于：定义、起源、核心要义
- 我的理解：沟通的语气由“股东是谁”决定——既然是合伙人，就该如实交代，而不是对市场公关。

## 卡片 2：位置互换的披露准则

- 原话：我们将坦诚地向各位报告，着重强调那些对评估企业价值至关重要的优点和缺点。我们的准则是：假如你我位置互换，我们想知道的所有商业事实，都会毫无保留地告诉你。
- 来源：1983 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1983-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：核心准则、误解纠正
- 我的理解：信息披露的标准不是监管下限，而是合伙人换位后真正想知道的事实。

## 卡片 3：坦诚对管理者本身有益

- 原话：我们坚信，对于管理层而言，坦诚是有益的：误导公众的CEO 最终也会误导自己。
- 来源：1996 年伯克希尔股东手册
- 文件：`buffett/interview/ba-fei-te-1996nian-bo-ke-xi-er-gu-dong-shou-ce.md`
- 可用于：核心要义、报忧的理由
- 我的理解：坦诚不只是对股东的义务，更是防止自我欺骗的护栏。

## 卡片 4：不玩记分牌游戏

- 原话：我们会始终坦诚地告诉你，每个洞我们打了多少杆，永远不会玩记分牌的游戏。
- 来源：1996 年伯克希尔股东手册
- 文件：`buffett/interview/ba-fei-te-1996nian-bo-ke-xi-er-gu-dong-shou-ce.md`
- 可用于：核心要义、与会计的关系
- 我的理解：沟通诚信的底层是不操纵数字——不平滑业绩、不做大洗澡。

## 卡片 5：所有股东同时获得相同信息

- 原话：在所有的交流中，我们都尽力确保没有一名股东获得优待：我们不会随大流，向证券分析师或者大股东们提供利润指引或其它有价值的信息。我们的目标是让我们的所有股东在同一时间获得相同的信息。
- 来源：1996 年伯克希尔股东手册
- 文件：`buffett/interview/ba-fei-te-1996nian-bo-ke-xi-er-gu-dong-shou-ce.md`
- 可用于：核心要义、与股东利益的关系
- 我的理解：公平沟通本身就是对全体股东利益的保护，不给任何人开小灶。

## 卡片 6：CEO 应亲自向股东汇报

- 原话：各位的董事长坚信，股东有权直接听取首席执行官讲述公司正在发生什么，以及他对公司当前和未来前景的评价。……一年一度的经营报告不应该被交给什么内部专员或公关顾问去代写。
- 来源：1979 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1979-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：定义、起源、常见问题
- 我的理解：股东有权直接听 CEO 说话，年报是经理人对老板的交代，不是公关稿。

## 卡片 7：沟通会筛选股东群体

- 原话：在很大程度上，一家公司会吸引到它所追求的、也是它所配得上的那类股东群体。如果公司把思考和沟通的重心放在短期业绩或短期股价波动上，在很大程度上，它就会吸引到同样关注这些因素的股东。
- 来源：1979 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1979-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：思想演变、长期股东、总结
- 我的理解：沟通风格像餐厅菜单，长期取向的坦诚会留下长期股东，短期话术会引来短线客。
