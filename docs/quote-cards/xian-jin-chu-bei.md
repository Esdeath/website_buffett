# 现金储备：原话卡片

## 卡片 1：现金像氧气

- 原话：现金——可用的现金或授信额度——很像氧气：你在 99.9% 的时间里不会注意到它，直到缺氧的时候……如果氧气消失了，那它就是你唯一需要关注的东西。
- 来源：2014 年伯克希尔股东大会
- 文件：`buffett/shareholders/2014nian-bo-ke-xi-er-gu-dong-da-hui.md`
- 可用于：定义、核心原则
- 我的理解：现金的价值不在平时，而在缺它的那一刻；那一刻它就是一切。

## 卡片 2：现金在自己口袋好过在别人口袋

- 原话：抱着一堆现金从来不会让我们开心。但让这些钱在伯克希尔的口袋里烧出洞来，总好过让它们舒舒服服地躺在别人的口袋里。
- 来源：1998 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1998-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：核心原则、机会成本
- 我的理解：现金让人不开心，但保留控制权比追逐收益更重要。

## 卡片 3：永不依赖陌生人的善意

- 原话：我们永远不会依赖陌生人的善意。“大到不能倒”不是伯克希尔的退路。相反，我们始终安排好自己的事务，使得任何我们可能面临的现金需求，都会被自身的流动性所淹没。
- 来源：2009 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2009-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：自给自足、危机
- 我的理解：现金储备的终极目的，是在任何动荡中都不必求人。

## 卡片 4：找不到机会难受，但乱投资遭殃

- 原话：400 亿美元拿在手里，对我和查理来说，是个心思。找不到机会虽然难受，但乱投资要遭殃。
- 来源：2005 年堪萨斯大学学生问答
- 文件：`buffett/interview/ba-fei-te-2005nian-dui-hua-kan-sa-si-da-xue-xue-sheng.md`
- 可用于：耐心、纪律
- 我的理解：现金保护的是不犯错的纪律；宁可难受地等，也不勉强出手。

## 卡片 5：现金有机会成本

- 原话：如此超常的流动性只能获得微不足道的回报，远远超出查理和我希望伯克希尔保持的水平。等到我们把伯克希尔的冗余资金重新配置到更具生产力的资产中时，我们的笑容才会更灿烂。
- 来源：2017 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2017-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：机会成本、误解纠正
- 我的理解：巴菲特从不假装现金免费；储备是用回报换安全和行动力。

## 卡片 6：到那时只有现金靠得住

- 原话：到期的债务必须用真金白银来偿还。到了那时候，只有现金才靠得住。
- 来源：2010 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2010-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：反面（杠杆）、危机
- 我的理解：信用会在最需要时消失，能偿债、能行动的只有真金白银。
