# 短期国债：原话卡片

## 卡片 1：不依赖商业票据、授信或债券市场

- 原话：你们的公司还持有大量的现金和美国国库券，远超传统智慧所认为的必要水平。在 2008 年的恐慌中，伯克希尔靠自身经营产生现金，完全不依赖任何商业票据、银行授信或债券市场。
- 来源：2023 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2023-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：定义、核心原则
- 我的理解：短期国债加自身现金，让伯克希尔在恐慌中无需求人。

## 卡片 2：持有国债，不靠商业票据和授信

- 原话：正因为如此，我们持有短期国债，而不是商业票据。我们不能靠银行信用额度。谁都不知道群体恐慌什么时候爆发。
- 来源：2020 年接受 CNBC 采访
- 文件：`buffett/interview/ba-fei-te-2020nian-jie-shou-cnbczhuan-fang.md`
- 可用于：核心原则、反面对照
- 我的理解：恐慌时商业票据和授信会消失，只有国债靠得住。

## 卡片 3：每周一买国债

- 原话：每到星期一，我们都会买国债……我们把所有的钱都保持短期存放，存放在国债里。
- 来源：2023 年接受 CNBC 采访
- 文件：`buffett/interview/ba-fei-te-2023nian-jie-shou-cnbczhuan-fang.md`
- 可用于：操作、不择时
- 我的理解：买国债是机械动作，不预测利率；钱永远保持短期可用。

## 卡片 4：平均期限 88 天

- 原话：截至 2017 年底，伯克希尔持有 1,160 亿美元的现金和美国国库券（平均期限 88 天）。
- 来源：2017 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2017-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：案例、期限
- 我的理解：极短的期限让上千亿资金几乎不承担利率和通胀风险。

## 卡片 5：遗嘱里的 10% 短期政府债券

- 原话：把 10% 的现金投入短期政府债券，把 90% 投入一只低费率的标普 500 指数基金。
- 来源：2013 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2013-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：普通人配置、案例
- 我的理解：短期国债作为防御性、流动性配置，连普通家庭方案里也有它。

## 卡片 6：危机前只持有美国国债

- 原话：这场危机爆发之前，我的个人账户没有投资任何股票，只持有美国国债。
- 来源：2008 年《纽约时报》文章《买入美国，正当时》
- 文件：`buffett/interview/ba-fei-te-2008nian-mai-ru-mei-guo-zheng-dang-shi.md`
- 可用于：案例、等待时机
- 我的理解：在没有好机会时，短期国债是安全的停泊处，等待出手。
