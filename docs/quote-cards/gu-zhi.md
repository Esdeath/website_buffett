# 估值：原话卡片

## 卡片 1：估值就是现金流折现

- 原话：今天任何一只股票、债券或一家企业的价值，取决于在其剩余存续期间预期发生的现金流入和流出——以适当的利率折现后的现值。请注意，这个公式对股票和债券同样适用。
- 来源：1992 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1992-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：定义、数学根基
- 我的理解：估值的本体是一道折现题，不是套倍数；股票和债券只是未来"票息"是否已知的区别。

## 卡片 2：折现值最便宜的才该买

- 原话：经现金流折现计算后最便宜的那个投资，就是投资者应该购买的——不管它的企业是否成长，盈利是否波动，当前价格相对于当前盈利和账面价值是高还是低。
- 来源：1992 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1992-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：核心原则、成长与价值
- 我的理解：估值的唯一标准是折现值，市盈率市净率的高低只是表象。

## 卡片 3：常见指标本身与估值无关

- 原话：常见的估值指标如股息率、市盈率、市净率，甚至增长率，本身与估值毫无关系——除非它们能为一家企业未来现金流入和流出的金额及时间提供线索。
- 来源：2000 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2000-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：误解纠正、核心原则
- 我的理解：倍数只是线索，不是估值本身；离开现金流谈估值指标就是噪音。

## 卡片 4：能预测现金流，就能估值

- 原话：如果你能告诉我一家企业从现在到结束经营时的现金流入和现金支出将是多少，假设我知道适合的利率，我就能告诉你这家企业的价值。这并不取决于这家企业是卖悠悠球、呼啦圈还是电脑。
- 来源：1991 年圣母大学演讲
- 文件：`buffett/interview/ba-fei-te-1991nian-sheng-mu-da-xue-yan-jiang.md`
- 可用于：实操方法、能力圈
- 我的理解：估值与行业无关，关键是能否预测现金流；不能预测就放弃。

## 卡片 5：内在价值是现金流的贴现值之和

- 原话：内在价值是一个非常重要的概念。它提供了唯一合乎逻辑的评估价值的方法。内在价值的定义非常简单：它是一项业务在其存续期内，所能获得的所有现金流的贴现值之和。
- 来源：1996 年伯克希尔股东手册
- 文件：`buffett/interview/ba-fei-te-1996nian-bo-ke-xi-er-gu-dong-shou-ce.md`
- 可用于：定义、与内在价值的关系
- 我的理解：估值就是计算内在价值的过程，二者一体两面。

## 卡片 6：估值不必精确

- 原话：使用精确的数字实际上是愚蠢的做法；更好的方法是在一个可能的范围内进行估算。
- 来源：2000 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2000-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：误解纠正、安全边际
- 我的理解：估值给的是区间不是定点，精确感是假象，余地才是保护。

## 卡片 7：估值无法精确到小数点

- 原话：显然，我们不认为我们对企业价值的估算能够精确到小数点后第二位或者第三位。不过，对于某些企业，我们还是十拿九稳的。
- 来源：1997 年伯克希尔股东大会
- 文件：`buffett/shareholders/1997nian-bo-ke-xi-er-gu-dong-da-hui.md`
- 可用于：误解纠正、核心原则
- 我的理解：估值的把握来自筛选对企业，而不是来自更精密的模型。
