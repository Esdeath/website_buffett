# 内在价值：原话卡片

- 原话：真正重要的，当然是每股内在商业价值的增长率，而非账面价值。
- 来源：1987 巴菲特致股东信
- 年份：1987
- 文件路径：buffett/berkshire/gu-dong-xin/1987-ba-fei-te-zhi-gu-dong-xin.md

- 可用于：定义 / 误解纠正
- 我的理解：账面价值只是会计数字，内在价值才是企业经济能力的核心。

- 原话：在做投资时，我们把自己定位为企业分析师，而非市场分析师、宏观经济分析师，甚至也不是证券分析师。
- 来源：1987 巴菲特致股东信
- 年份：1987

- 相关关键词：内在价值、企业价值、股票市场
- 可用于：核心原则
- 我的理解：内在价值要求把股票看成企业所有权，而不是报价符号。

- 原话：今天任何一只股票、债券或一家企业的价值，取决于在其剩余存续期间预期发生的现金流入和流出——以适当的利率折现后的现值。
- 来源：1992 巴菲特致股东信
- 年份：1992
- 文件路径：buffett/berkshire/gu-dong-xin/1992-ba-fei-te-zhi-gu-dong-xin.md
- 类型：致股东信
- 相关关键词：内在价值、现金流、估值
- 可用于：定义 / 主引用
- 我的理解：这是巴菲特最标准的内在价值公式，关键难点不在数学，而在估计未来现金流。

- 原话：如果一家企业很复杂，或者所处的行业变化不断，我们就没有足够的聪明才智去预测其未来的现金流。

- 我的理解：内在价值估算必须以能力圈为前提，无法估计现金流就不能硬算。

- 原话：如果你试着评估内在价值，就会发现全都与现金流有关。

- 原话：使用无风险利率作为折现率还与确定程度的高低有关。这是一个基准利率。

- 我的理解：折现率在巴菲特体系里首先是比较基准，而不是复杂模型的装饰。

- 原话：常见的估值指标如股息率、市盈率、市净率，甚至增长率，本身与估值毫无关系——除非它们能为一家企业未来现金流入和流出的金额及时间提供线索。
