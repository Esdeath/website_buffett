# 纪律：原话卡片

- 原话：合理的保单他就签，不合理的一概拒绝。
- 可用于：承保纪律、拒绝亏损业务
- 我的理解：纪律不是追求业务量，而是在价格不合理时接受暂时闲置。

- 原话：鼓励大量下注，因为概率对他有利，但拒绝任何一笔巨大的单注。
- 可用于：仓位控制、概率思维
- 我的理解：看好预期收益不等于忽视单笔失败的破坏力，下注方式必须与风险结构匹配。

- 原话：在投资中有一条很重要的纪律，一个投资输了，不要为了翻本而再追加投资。
- 可用于：沉没成本、亏损后加码
- 我的理解：追加投资必须依据当前价值，而不能依据过去损失和翻本愿望。

- 原话：重要的是现实主义和纪律。如果你现实而自律，你不需要特别聪明就能做好投资。
- 可用于：投资方法、能力与性格
- 我的理解：如实判断现实并长期执行规则，比追求复杂和炫目的判断更可靠。

- 原话：必须有人要根据常识说，“我们只是不这么做。”
- 可用于：制度边界、复杂金融工具
- 我的理解：面对复杂性和群体压力，纪律最终体现为清楚、坚定的拒绝。

- 原话：有纪律的回购是*最稳妥*的明智用钱方式：以8毛钱或更低的价格买1美元的东西，很难犯错。
- 可用于：股票回购、资本配置
- 我的理解：回购不是态度表达，只有价格显著低于保守估计的内在价值时才创造价值。

- 原话：所有保险公司都把承保纪律挂在嘴边。而在伯克希尔，这是一种信仰，旧约风格的。
- 可用于：保险文化、长期执行
- 我的理解：真正的纪律不是写在制度里，而是在行业竞争最激烈时仍不降低标准。
