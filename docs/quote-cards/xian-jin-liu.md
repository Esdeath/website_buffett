# 现金流：原话卡片

## 卡片 1：评估内在价值全都与现金流有关

- 原话：如果你试着评估内在价值，就会发现全都与现金流有关。
- 来源：1997 年伯克希尔股东大会
- 文件：`buffett/shareholders/1997nian-bo-ke-xi-er-gu-dong-da-hui.md`
- 可用于：定义、总结
- 我的理解：价值的唯一来源就是企业未来产生的现金，现金流是估值的根基。

## 卡片 2：伊索寓言三问

- 原话：这位先知就是伊索，他那经久不衰但略嫌不够完整的投资洞见是：“一鸟在手，胜过二鸟在林。”要充实这个原则，你只需回答三个问题：你有多大把握确定树林里确实有鸟？它们什么时候会飞出来，数量有多少？无风险利率是多少？
- 来源：2000 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2000-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：定义、估值方法
- 我的理解：现金流折现被浓缩成三问——有多少现金、何时到、用什么利率折现。

## 卡片 3：市盈率市净率本身与估值无关

- 原话：常见的估值指标如股息率、市盈率、市净率，甚至增长率，本身与估值毫无关系——除非它们能为一家企业未来现金流入和流出的金额及时间提供线索。
- 来源：2000 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2000-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：核心要义、常见误解
- 我的理解：这些指标只是现金流的线索，不是价值本身；价值始终是现金流的折现。

## 卡片 4：企业是张未标明息票的债券

- 原话：其实企业也有息票，这些息票未来会发生变化，只不过没有印在股票上。因此，企业未来的息票要由投资者自己来估计。
- 来源：1997 年伯克希尔股东大会
- 文件：`buffett/shareholders/1997nian-bo-ke-xi-er-gu-dong-da-hui.md`
- 可用于：定义、核心要义
- 我的理解：企业的未来现金流就像债券的息票，只是要靠投资者自己估出来。

## 卡片 5：现金流谬误——只加不减

- 原话：所有这些都揭示了华尔街报告中经常引用的”现金流”概念的荒谬性。这些数字通常包含了(a)加(b)——却不减去(c)。
- 来源：1986 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1986-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：边界、常见误解
- 我的理解：真正用于估值的现金流必须减去维持性资本开支，否则就是高估价值的假数字。

## 卡片 6：现金流对重资产行业的口径无效

- 原话：但”现金流”在制造业、零售业、采掘业和公用事业等行业中毫无意义，因为对这些行业来说，(c)始终是一个重大数字。
- 来源：1986 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1986-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：跨行业案例、误解纠正
- 我的理解：需要持续投资的行业，忽略资本开支的“现金流”毫无意义，只有桥梁、气田这类例外才接近真实。

## 卡片 7：估不出现金流就看下一家

- 原话：计算出这些未来的现金流可能是什么。当你不能——当你觉得你不能在这方面做出合理的估计，你就会看下一家公司。
- 来源：2003 年伯克希尔股东大会
- 文件：`buffett/shareholders/2003nian-bo-ke-xi-er-gu-dong-da-hui.md`
- 可用于：能力圈、现实判断
- 我的理解：现金流估不出来时，正确的反应是放弃这家公司，而不是硬猜一个数字。
