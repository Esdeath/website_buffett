# 消费者垄断：原话卡片

## 卡片 1：占主导地位的报纸是最好的生意之一

- 原话：一家占据主导地位的报纸，其经济效益是极为出色的，堪称整个商业世界中最好的之一。
- 来源：1984 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1984-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：定义、报纸案例、起源
- 我的理解：消费者垄断的威力，巴菲特最早是从本地报纸生意里看清的。

## 卡片 2：糟糕的报纸也不可或缺

- 原话：但即使是一份糟糕的报纸，对大多数市民来说仍然物超所值，仅仅因为它的”布告栏”价值。
- 来源：1984 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1984-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：核心要义、垄断与质量解绑
- 我的理解：消费者垄断让盈利和经营质量脱钩，这是它最反直觉、也最强大的地方。

## 卡片 3：经济特许经营权的三条件

- 原话：经济特许经营权产生于这样的产品或服务：(1) 它是被需要或被渴望的；(2) 顾客认为找不到近似的替代品；(3) 不受价格管制。
- 来源：1991 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1991-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：定义、起源、与定价权的关系
- 我的理解：消费者垄断的本质，就是被需要、无替代、不受管制这三条。

## 卡片 4：可口可乐和吉列是“不可战胜的”

- 原话：在今年的年报中，我们谈论过可口可乐和吉列，我把他们的基本业务称作是“不可战胜的”。
- 来源：1997 年伯克希尔股东大会
- 文件：`buffett/shareholders/1997nian-bo-ke-xi-er-gu-dong-da-hui.md`
- 可用于：核心要义、可口可乐/吉列案例
- 我的理解：消费者垄断的极致，就是巴菲特敢用“不可战胜”来形容的那种生意。

## 卡片 5：绝不会出现第二个可口可乐

- 原话：软饮料行业绝不会出现第二个可口可乐。可口可乐取得现在的地位花了100多年时间。
- 来源：1997 年伯克希尔股东大会
- 文件：`buffett/shareholders/1997nian-bo-ke-xi-er-gu-dong-da-hui.md`
- 可用于：核心要义、不可复制性
- 我的理解：真正的消费者垄断是时间和心智堆出来的，砸钱也复制不了。

## 卡片 6：成功归功于垄断和裙带关系

- 原话：他一生的成功全部归功于美国的两项制度：垄断和裙带关系。
- 来源：1992 年巴菲特奥马哈新闻俱乐部演讲
- 文件：`buffett/interview/ba-fei-te-1992nian-ba-fei-te-ao-ma-ha-xin-wen-ju-le-bu.md`
- 可用于：报纸案例、垄断的盈利根源
- 我的理解：巴菲特借出版商的玩笑话，点破报纸盈利更多来自本地垄断而非质量。

## 卡片 7：刀枪不入的特许经营权一去不复返

- 原话：只是那种刀枪不入的特许经营权和取之不尽的丰裕暴利的时代，已经一去不复返了。
- 来源：1991 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1991-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：现实判断、垄断的衰退、误解纠正
- 我的理解：再强的消费者垄断也不是永恒的，技术和竞争会慢慢把它稀释。
