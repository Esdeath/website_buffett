# 子女教育：原话卡片

## 卡片 1：父母是天生的价值观老师

- 原话：父母是每个人的第一任价值观导师。每个孩子都追随自己的榜样，学错了就坏了。父母是孩子天生的榜样。孩子们自然而然地效仿自己的父母，父母的价值观正确，孩子的价值观一般也错不了。
- 来源：2001 年巴菲特对话内布拉斯加大学
- 文件：`buffett/interview/ba-fei-te-2001nian-dui-hua-nei-da-shang-xue-yuan.md`
- 可用于：定义、核心要义
- 我的理解：子女教育第一性是价值观，传递靠身教而非说教。

## 卡片 2：最初几年最重要

- 原话：世界上最重要的事情就是你在最初几年教给孩子们的东西。请确保你配得上成为他们的英雄，因为你会成为他们的英雄。作为父母，你无时无刻不处于教师的位置上。
- 来源：2003 年巴菲特对话沃顿商学院学生
- 文件：`buffett/interview/ba-fei-te-2003nian-dui-hua-wo-dun-shang-xue-yuan-xue-sheng.md`
- 可用于：核心要义、时间窗口
- 我的理解：父母无时不在教育，最初几年的言行塑造孩子一生底色。

## 卡片 3：足够多，但不至于太多（最早表述）

- 原话：我基本上认为，如果你很富有，你应该给你的孩子留下或给他们足够的钱，足以让他们做任何事情，但不足以让他们什么都不做。
- 来源：1994 年内布拉斯加大学演讲
- 文件：`buffett/interview/ba-fei-te-1994nian-nei-bu-la-si-jia-da-xue-yan-jiang.md`
- 可用于：财富原则、定义
- 我的理解：子女教育里最敏感的「给多少钱」，答案是分寸而非数额。

## 卡片 4：足够做任何事，而非足够无所事事

- 原话：富人留给孩子的财富应该足够他们做任何事情，而不是足够他们无所事事。
- 来源：2006 年我为什么慷慨解囊
- 文件：`buffett/interview/ba-fei-te-2006nian-wo-wei-shi-me-kang-kai-jie-nang.md`
- 可用于：财富原则、误解纠正
- 我的理解：过多的钱会废掉孩子，给底气而非给放纵。

## 卡片 5：这句话来自凯瑟琳·格雷厄姆

- 原话：我们也打算留给孩子们足够的财富，让他们“可以做任何事，但不能什么都不做”。这是凯瑟琳·格雷厄姆跟我说的一句话，确实很有道理。你如果很富有，让孩子一贫如洗当然不妥，但让他们一辈子不需要努力也同样荒唐。
- 来源：2021 年采访《沃伦·巴菲特的投资策略》
- 文件：`buffett/interview/ba-fei-te-2021nian-cai-fang-wo-lun-ba-fei-te-de-tou-zi-ce-lue-ru-he-xiang-chuan-qi-yi-yang-sheng-huo-he-tou-zi-wan-zheng-fang-tan.md`
- 可用于：来源、案例
- 我的理解：连这条原则的出处都坦白说明，分寸在「贫」与「废」之间。

## 卡片 6：前五年不可重来，永不讽刺孩子

- 原话：最重要的是孩子——孩子生命中的前5年至关重要，这几年是他们成长发育的关键时期，一旦错过就无法重来。永远不要对孩子使用讽刺的语言。
- 来源：2005 年加州大学问答
- 文件：`buffett/interview/ba-fei-te-2005nian-jia-zhou-da-xue-luo-shan-ji-fen-xiao-an-de-sen-guan-li-xue-yuan-nan-jia-zhou-da-xue-ma-xie-er-shang-xue-yuan-wen-da-ji-yao.md`
- 可用于：时间窗口、日常实践
- 我的理解：父母的情绪与言语本身就是教育，前五年错过无法重来。
