# 管理层动机：原话卡片

## 卡片 1：制度迫力让理性枯萎

- 原话：我当时以为，正派、聪明且经验丰富的管理者自然而然会做出理性的商业决策。但随着时间推移我发现并非如此。相反，当制度迫力发挥作用时，理性往往会枯萎。
- 来源：1989 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1989-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：定义、核心洞察
- 我的理解：能力和正派都不能保证理性，动机被制度裹挟时好人也会犯错。

## 卡片 2：盲目模仿源于制度迫力而非贪腐

- 原话：同行公司的行为——不管是扩张、收购还是设定高管薪酬等等——都会被盲目模仿。推动企业走上这些往往是错误道路的，是制度迫力，而非贪腐或愚蠢。
- 来源：1989 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1989-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：制度迫力机制、误解纠正
- 我的理解：坏决策常常出自被错误动机结构裹挟的好人，而非坏人。

## 卡片 3：不与缺乏令人钦佩品质的人为伍

- 原话：无论一家公司的前景多么诱人，我们都不愿与缺乏令人钦佩品质的管理者为伍。跟坏人做生意永远不会有好结果。
- 来源：1989 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1989-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：核心要义、选人原则
- 我的理解：动机可疑的人，再好的生意也不值得合作。

## 卡片 4：能力或动机可疑就给估值打折

- 原话：如果预期 CEO 能把再投资这件事做好，再投资前景就会给公司的当前价值加分；如果 CEO 的能力或动机令人起疑，当前价值就得打折扣。
- 来源：2010 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2010-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：动机进入估值
- 我的理解：判断管理层，能力和动机要一起看，动机可疑同样要打折。

## 卡片 5：从未忘记经手的是别人的钱

- 原话：Gene 从未忘记自己经手的是别人的钱。虽然这种受托人的态度始终占据主导，但他精湛的管理技能使得这家银行的盈利能力经常在全美名列前茅。
- 来源：1980 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1980-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：好动机范例、受托人态度
- 我的理解：把别人的钱当自己的钱守护，是值得信任的管理层动机的核心。

## 卡片 6：搞砸了你们的钱，他们自己也会赔钱

- 原话：如果他们搞砸了你们的钱，他们自己也会赔钱……我们的董事以极大的热情和所有者的眼光来监督伯克希尔的行动和业绩。
- 来源：2010 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2010-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：动机绑定、治理
- 我的理解：用真金白银把动机和股东绑在一起，远胜口号和承诺。

## 卡片 7：带着所有者的心态加入

- 原话：他们带着所有者的心态加入我们，而我们提供的环境鼓励他们保持这种心态。拥有一批热爱自己企业的管理者，可不是什么小优势。
- 来源：2010 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2010-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：所有者心态、文化
- 我的理解：好动机既靠选对人，也靠环境去呵护和保持。
