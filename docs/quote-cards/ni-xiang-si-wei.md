# 逆向思维：原话卡片

- 原话：真正的保守投资，来自正确的前提、准确的事实和合理的逻辑。遵循这三点做出的决定，有时与常规相符，但更多时候是与常规背道而驰的。
- 可用于：定义逆向思维
- 我的理解：与常规不同只是事实与逻辑可能产生的结果，不是预先追求的姿态。

- 原话：我们不会因为重要的人、能言善辩的人，或大多数人赞同我们，而感到踏实。也不会因为他们不赞同，而感到不安。民意调查替代不了独立思考。
- 可用于：多数意见与独立判断
- 我的理解：同意人数不能验证投资结论，反对人数也不能推翻有证据的判断。

- 原话：你需要的是一个稳定的性格，你需要一种气质，不是从盲目从众或一意孤行中获得极大快乐，因为这不是一个需要民意投票来决定的行业，而是一个需要你深度思考来决定的行业。
- 可用于：纠正机械逆向
- 我的理解：盲从和为了反对而反对都在用群体替代事实，只是方向相反。

- 原话：你之所以是对的，是因为你的事实和推理是正确的。
- 可用于：判断正确性的标准
- 我的理解：逆向判断最终必须由事实、推理和价值测算负责。

- 原话：市场先生是来为你服务的，不是来引导你的。对你有用的是他的钱包，而不是他的智慧。
- 可用于：利用市场波动
- 我的理解：市场报价可以提供交易机会，但不能代替对企业价值的判断。

- 原话：一家企业或一只股票仅仅因为不受待见就值得买入——逆向操作和从众心理一样愚蠢。关键是独立思考，而非随波逐流。
- 可用于：逆向思维的边界
- 我的理解：冷门、下跌和悲观都不是买入理由，价格相对价值足够低才是。

- 原话：恐惧传播得很快，是具有传染性的。这与智商无关。信心只会一次一个地恢复，而不会大规模恢复。
- 可用于：危机中的群体情绪
- 我的理解：极端情绪会造成价格错位，但投资者必须先保证流动性和判断能力，才能利用它。
