# 集中投资：原话卡片

## 卡片 1：最多 40% 净资产押一笔

- 原话：一笔投资，我们掌握了事实和逻辑，正确的概率极大，与此同时，这笔投资的内在价值不可能出现根本变化，出错的概率很小，在这种情况下，我们可能最多拿出 40％ 的净资产用于这笔投资。
- 来源：1965 年巴菲特致合伙人信
- 文件：`buffett/berkshire/he-huo-ren-xin/1965-ba-fei-te-zhi-he-huo-ren-xin.md`
- 可用于：定义、核心原则
- 我的理解：集中的前提是确定性，不是胆量；只有在事实逻辑都站得住时才敢重注。

## 卡片 2：下重注换长期领先

- 原话：一旦看准了最佳投资机会，我愿意下重注集中投资。我很清楚，我这么操作可能偶尔一年业绩特别差，要是分散了，就没这个情况。我们的业绩波动幅度更大，但是从长期来看，我们的领先优势也更大。
- 来源：1965 年巴菲特致合伙人信
- 文件：`buffett/berkshire/he-huo-ren-xin/1965-ba-fei-te-zhi-he-huo-ren-xin.md`
- 可用于：核心原则、波动代价
- 我的理解：集中以年度波动为代价，换取长期更大的领先；这是有意识的取舍。

## 卡片 3：九年只有五六笔超过 25%

- 原话：我们能投入 40％ 的仓位，肯定是遇到了特别罕见的情况。正因为罕见，抓准了机会，才要下重注……合伙基金成立九年来，我们仓位超过 25％ 的投资也只有五六笔。
- 来源：1965 年巴菲特致合伙人信
- 文件：`buffett/berkshire/he-huo-ren-xin/1965-ba-fei-te-zhi-he-huo-ren-xin.md`
- 可用于：误解纠正、门槛
- 我的理解：集中是罕见的例外，不是天天满仓；门槛极高，永久损失风险要极低。

## 卡片 4：做对很少的决定就够

- 原话：你必须在证券市场上做出很少的正确决定才能获得巨额财富。你不必做一百件聪明的事情。
- 来源：1994 年内布拉斯加大学演讲
- 文件：`buffett/interview/ba-fei-te-1994nian-nei-bu-la-si-jia-da-xue-yan-jiang.md`
- 可用于：逻辑基础、常见问题
- 我的理解：财富来自少数想透的好机会，而不是机会数量；这是集中投资的根。

## 卡片 5：不该超过六个生意

- 原话：要是你真能看懂生意，你拥有的生意不应该超过六个……靠第七个最好的主意发家的人很少，靠最好的主意发家的人很多。
- 来源：1998 年佛罗里达大学演讲
- 文件：`buffett/interview/ba-fei-te-1998nian-fo-luo-li-da-da-xue-yan-jiang.md`
- 可用于：数量上限、误解纠正
- 我的理解：过度分散会稀释最好的主意；六个好生意已经足够分散。

## 卡片 6：把所有鸡蛋放一个篮子也安心

- 原话：查理和我对这种把所有鸡蛋放在一个篮子里的做法很安心，因为伯克希尔拥有各种类型绝对非凡的业务。
- 来源：1996 年伯克希尔股东手册
- 文件：`buffett/interview/ba-fei-te-1996nian-bo-ke-xi-er-gu-dong-shou-ce.md`
- 可用于：案例、内部多元
- 我的理解：集中持有一家公司不等于不分散；篮子里的生意本身可以高度多元。
