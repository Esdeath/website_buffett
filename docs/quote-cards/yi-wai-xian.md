# 意外险：原话卡片

- 原话：保险业把职业过失保险和某些其他类型的责任保险称为”长尾”业务，以表明保险公司在将理赔金最终支付给索赔人及其律师（还有*保险公司自己的*律师）之前，可以持有大笔资金相当长的一段时间。
- 来源：1990 巴菲特致股东信
- 年份：1990
- 文件路径：buffett/berkshire/gu-dong-xin/1990-ba-fei-te-zhi-gu-dong-xin.md
- 类型：致股东信
- 相关关键词：意外险、浮存金、承保
- 可用于：定义 / 主引用
- 我的理解：长尾意外险因为赔付拖很久，所以能让保险公司长期持有大笔浮存金。

- 原话：之所以能积累浮存金，是因为索赔往往在所谓的过失发生很长一段时间之后才被提出，而且由于冗长的诉讼程序，赔付可能还会进一步拖延。

- 可用于：浮存金来源
- 我的理解：意外险浮存金存续期长，源于索赔晚提出、诉讼又拖延。

- 原话：在长尾业务中，综合比率为115（甚至更高）仍可能是有利可图的，因为浮存金产生的投资收益将超过赔付和费用超出保费15%的部分。

- 我的理解：长尾意外险因为浮存金存续期长，承保略亏（综合比率115）也可能整体盈利。

- 原话：但保险公司如果以这些比率作为定价目标，那注定会亏损。相反，保费定价必须留出充足的安全边际，以应对那些永远会给保险业带来昂贵意外的社会趋势。

- 我的理解：长尾意外险即便能容忍承保略亏，也不能把略亏当目标，否则必然真亏。

- 原话：“长尾”意味着的恰恰就是：某一年承保的责任险业务，最初假设综合比率为115，但随着年复一年的索赔纠缠，最终全部结案后可能变成200、300甚至更糟。

- 原话：保险公司先收保费、后付赔款。在一些极端情况下，比如某些工伤赔偿事故，赔付可以延续数十年之久。

- 原话：然而，另一些险种却能让高管和股东在公司走向破产的路上还洋洋自得。想想医疗事故险或产品责任险。在这些”长尾”险种中，一家财产意外险公司可以连续多年——甚至几十年——向所有者和监管机构报告巨额但虚假的利润。

- 原话：由于我们的业务侧重于意外险和再保险，与专做财产保险的公司相比，我们在估算赔付成本上面临更多困难。
