# 企业收购价格：原话卡片

## 卡片 1：价格过高抵消十年好业务

- 原话：对投资者来说，即便是一家极其优秀的公司，买入价格过高就可能抵消其后十年靓丽的业务发展。
- 来源：1982 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1982-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：核心原则、定义
- 我的理解：质量决定能赚多少，价格决定已经付出多少；买贵了再好的生意也救不回。

## 卡片 2：整体收购几乎注定付全价甚至超全价

- 原话：公司并购的竞争本质几乎注定了在整体收购另一家企业时，必须支付全价——甚至常常超过全价。但证券市场的竞价拍卖机制，却时常让经营优秀的公司有机会以不到通过协商收购获得同等盈利能力所需价格 50% 的代价，买回自家的一部分业务。
- 来源：1980 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1980-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：控制权溢价、核心原则
- 我的理解：控制权要付溢价，市场买部分股权常常便宜得多。

## 卡片 3：合理价格买好公司

- 原话：以合理的价格买入一家好公司，远远好过以便宜的价格买入一家普通的公司。
- 来源：1989 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1989-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：价格上限、误解纠正
- 我的理解：价格纪律是不多付，而非只买最便宜；合理价格才是上限。

## 卡片 4：不为管理魔法付双倍价

- 原话：投资者随时可以按蟾蜍的市场价买到蟾蜍。如果投资者反而去资助那些想花双倍价钱亲吻蟾蜍的公主，那这些吻最好真有一些魔力。
- 来源：1981 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1981-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：反面、溢价
- 我的理解：高溢价多半是为“我能点石成金”的幻想买单。

## 卡片 5：协同效应是高价收购的借口

- 原话：我们还大手笔收购了瓦姆贝克磨坊，期望产生重要的协同效应（一个在商业界被广泛使用的术语，专门用来解释那些本身毫无道理的收购）。
- 来源：1985 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1985-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：反面、误解纠正
- 我的理解：协同效应常被用来为本身毫无道理的高价收购辩护。

## 卡片 6：市场价远低于协议收购价

- 原话：我们继续为保险投资组合寻找真正优秀的企业——通过证券市场的拍卖定价机制，以远低于那些平庸企业在协议收购中所要价格的水平，买入这些优秀企业的一小部分。
- 来源：1978 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1978-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：案例、价格纪律
- 我的理解：买优秀企业的部分股权，常比协议收购平庸企业还便宜。
