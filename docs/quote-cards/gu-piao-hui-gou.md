# 股票回购：原话卡片

- 原话：只有同时满足两个条件，查理和我才赞成回购：第一，公司有充裕的资金满足业务的运营和流动性需求；第二，以保守方法估算，股价相对于公司内在商业价值有很大的折扣。

- 原话：除非以低于内在价值的价格回购，否则继续持股的股东就是在受损害。
