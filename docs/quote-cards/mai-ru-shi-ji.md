# 买入时机：原话卡片

## 卡片 1：众人恐惧我贪婪

- 原话：我买股票遵循一个简单的规律：众人贪婪我恐惧；众人恐惧我贪婪。
- 来源：2008 年《纽约时报》文章《买入美国，正当时》
- 文件：`buffett/interview/ba-fei-te-2008nian-mai-ru-mei-guo-zheng-dang-shi.md`
- 可用于：定义、核心原则
- 我的理解：恐惧制造低价，贪婪制造高价；买点取决于情绪的反向，而非市场预测。

## 卡片 2：不预判，只反应

- 原话：我们从不试图预判这两种病症的到来或离去。我们的目标更为谦逊：我们只是在别人贪婪时尽量让自己恐惧，在别人恐惧时尽量让自己贪婪。
- 来源：1986 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1986-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：核心原则、起源
- 我的理解：择时是预测情绪来去，巴菲特只对已经发生的情绪做反应。

## 卡片 3：等知更鸟，春天就过了

- 原话：如果你等待知更鸟的到来，你将错过整个春天。
- 来源：2008 年《纽约时报》文章《买入美国，正当时》
- 文件：`buffett/interview/ba-fei-te-2008nian-mai-ru-mei-guo-zheng-dang-shi.md`
- 可用于：误解纠正、等好消息
- 我的理解：等好消息确认再买，往往为时已晚；机会在坏消息里。

## 卡片 4：坏消息是投资者的好朋友

- 原话：坏消息是投资者的好朋友。它帮你创造机会，让你打折买入一份美国的未来。
- 来源：2008 年《纽约时报》文章《买入美国，正当时》
- 文件：`buffett/interview/ba-fei-te-2008nian-mai-ru-mei-guo-zheng-dang-shi.md`
- 可用于：核心原则、案例
- 我的理解：恐慌不是躲开的理由，而是打折买入的机会。

## 卡片 5：滑向冰球将要去的地方

- 原话：目前，有一部分投资者手中紧握现金，他们以为自己有能力在更好的时机到来之后，再把现金投资出去……盯着球现在的位置，只能扑空。球将要去哪，我就去哪。
- 来源：2008 年《纽约时报》文章《买入美国，正当时》
- 文件：`buffett/interview/ba-fei-te-2008nian-mai-ru-mei-guo-zheng-dang-shi.md`
- 可用于：反面、紧握现金
- 我的理解：空等“更好时机”的人会扑空；要在别人观望时提前行动。

## 卡片 6：牛市无恐惧时正是该警惕时

- 原话：在我写这段文字的时候，华尔街几乎看不到一丝恐惧。到处洋溢着欢乐的气氛……但不幸的是，股票的表现不可能永远超越企业本身的业绩。
- 来源：1986 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1986-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：反面、牛市
- 我的理解：欢乐的牛市里没人恐惧，恰恰是该恐惧的时候。
