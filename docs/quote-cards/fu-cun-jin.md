# 浮存金：原话卡片

- 原话：浮存金是一笔我们持有但不属于我们的资金。
- 来源：1996 巴菲特致股东信
- 年份：1996
- 文件路径：buffett/berkshire/gu-dong-xin/1996-ba-fei-te-zhi-gu-dong-xin.md
- 类型：致股东信
- 相关关键词：浮存金、保险、承保
- 可用于：定义
- 我的理解：浮存金不是伯克希尔的自有资本，而是暂时可用、最终要履约偿付的保险负债。

- 原话：衡量我们保险业务的关键，第一是我们获取的“浮存金”规模有多大，第二是获取浮存金的成本有多高。
- 来源：1996 巴菲特致股东信
- 年份：1996
- 文件路径：buffett/berkshire/gu-dong-xin/1996-ba-fei-te-zhi-gu-dong-xin.md
- 类型：致股东信
- 相关关键词：浮存金、保险、资本配置
- 可用于：核心原则
- 我的理解：浮存金不能只看规模，成本同样关键；高成本浮存金可能是负担。

- 原话：在保险业务中，最重要的是浮存金的规模以及长期获取浮存金的成本。
- 来源：2005 巴菲特致股东信
- 年份：2005
- 文件路径：buffett/berkshire/gu-dong-xin/2005-ba-fei-te-zhi-gu-dong-xin.md
- 类型：致股东信
- 相关关键词：浮存金、保险、承保纪律
- 可用于：主引用 / 定义
- 我的理解：保险业务对伯克希尔的价值，不只是保费收入，而是能否长期低成本取得资金。

- 原话：浮存金是件美妙的事--前提是获取成本不能太高。
- 来源：2005 巴菲特致股东信
- 年份：2005
- 文件路径：buffett/berkshire/gu-dong-xin/2005-ba-fei-te-zhi-gu-dong-xin.md
- 类型：致股东信
- 相关关键词：浮存金、承保、承保纪律
- 可用于：误解纠正
- 我的理解：浮存金只有在承保价格合理、赔付和费用可控时才是优势。

- 原话：当保险公司取得承保利润时，浮存金的成本甚至低于零。
- 来源：2005 巴菲特致股东信
- 年份：2005
- 文件路径：buffett/berkshire/gu-dong-xin/2005-ba-fei-te-zhi-gu-dong-xin.md

- 相关关键词：浮存金、承保、承保利润
- 可用于：成本机制
- 我的理解：承保盈利意味着伯克希尔不仅免费使用资金，还因持有这笔资金获得额外收益。

- 原话：这种“先收钱、后付钱”的模式让我们手里持有大量资金--我们称之为“浮存金”。
- 来源：2011 巴菲特致股东信
- 年份：2011

- 相关关键词：浮存金、财产险、意外险
- 可用于：定义 / 机制
- 我的理解：财产意外险的时间差，是浮存金产生的基础。

- 原话：浮存金应该被视为一笔不断循环的基金。
- 来源：2011 巴菲特致股东信
- 年份：2011
- 文件路径：buffett/berkshire/gu-dong-xin/2011-ba-fei-te-zhi-gu-dong-xin.md

- 相关关键词：浮存金、内在价值、账面价值
- 可用于：估值
- 我的理解：会计上浮存金是负债，但如果它长期稳定、低成本，经济价值就不能简单按全额负债理解。

- 原话：我们浮存金的价值，是我们认为伯克希尔内在价值大幅超越账面价值的一个原因--一个非常重大的原因。
- 来源：2011 巴菲特致股东信

- 可用于：内在价值
- 我的理解：伯克希尔的保险浮存金使账面价值低估了真实经济价值。

- 原话：零成本的浮存金不是整个财产意外险行业可以期望的结果。
- 来源：2011 巴菲特致股东信
- 年份：2011

- 可用于：误解纠正
- 我的理解：浮存金优势不是保险行业自动拥有的，必须依靠承保能力和纪律。

- 原话：它显示为负债，但实际上是一笔巨大的资产。
- 来源：2016 伯克希尔股东大会

- 我的理解：在伯克希尔的条件下，浮存金的经济作用更接近可长期使用的低成本资金。

- 原话：如果我们的保费数量下降，我们的浮存金将会减少，但是速度会非常缓慢。
