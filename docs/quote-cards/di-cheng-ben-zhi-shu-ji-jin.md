# 低成本指数基金：原话卡片

## 卡片 1：遗嘱里的 90/10

- 原话：把 10% 的现金投入短期政府债券，把 90% 投入一只低费率的标普 500 指数基金。（我推荐先锋集团的基金。）我相信，这个策略的长期业绩将优于大多数投资者的成绩。
- 来源：2013 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2013-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：现实判断、核心原则
- 我的理解：最会选股的人，把自己最重要的钱交给指数，是对低成本指数最有力的背书。

## 卡片 2：几乎零成本的指数会赢专家

- 原话：我选择的投资——一只几乎零成本的非主动管理型标普 500 指数基金——随着时间推移，将会比大多数投资专家取得更好的成绩，不管这些“帮手们”多么声名显赫、激励机制多么诱人。
- 来源：2017 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2017-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：赌局动机、定义
- 我的理解：低成本本身就是优势；名气和激励都抵不过费用对回报的持续侵蚀。

## 卡片 3：对冲基金十年全面落后

- 原话：5 只 FOF 基金起步很快，2008 年全都跑赢了指数基金。然后就塌了。在此后的每一年里，FOF 基金整体都落后于指数基金。
- 来源：2017 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2017-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：案例、证据
- 我的理解：精英团队也敌不过低成本指数；短期可能领先，长期会被费用拖垮。

## 卡片 4：费用从不打折

- 原话：绩效有起有落，费用从不打折。
- 来源：2017 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2017-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：核心原则、误解纠正
- 我的理解：收益不确定，费用却确定地扣减；低成本是唯一能稳稳把握的变量。

## 卡片 5：什么都不懂也能跑赢专家

- 原话：通过定期投资指数基金，一个什么都不懂的投资者往往能跑赢大多数投资专家。矛盾的是，当“笨钱”认识到自己的局限时，它就不再笨了。
- 来源：1993 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1993-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：起源、普通人方案
- 我的理解：指数的优势不靠聪明，而靠低成本和不犯大错。

## 卡片 6：频繁换手只肥中间人

- 原话：唯一的后果就是，农场主群体的整体收益因为寻求建议和频繁换手产生的巨额费用而大幅缩水。
- 来源：2013 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/2013-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：跨领域案例、费用
- 我的理解：交易本身不创造价值，只把收益转移给收费的中间人；低成本被动持有才留住回报。
