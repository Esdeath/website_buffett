# 品格：原话卡片

## 卡片 1：最重要的是人格品质

- 原话：路易和他的三个儿子，都继承了布鲁姆金家族的商业才能、勤奋精神，以及最重要的——人格品质。更难得的是，他们都是非常好的人。
- 来源：1983 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1983-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：定义、核心要义
- 我的理解：品格被排在商业才能和勤奋之前，是巴菲特挑合伙人的最高标准。

## 卡片 2：才能、精力与正直的品格

- 原话：每一位都将卓越的才能、充沛的精力和正直的品格融为一体，创造出了杰出的财务成果。
- 来源：1987 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1987-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：核心要义、代表案例
- 我的理解：才能放大事业的规模，品格决定才能用在哪里。

## 卡片 3：绝不与缺乏令人钦佩品质的人为伍

- 原话：无论一家公司的前景多么诱人，我们都不愿与缺乏令人钦佩品质的管理者为伍。跟坏人做生意永远不会有好结果。
- 来源：1989 年巴菲特致股东信
- 文件：`buffett/berkshire/gu-dong-xin/1989-ba-fei-te-zhi-gu-dong-xin.md`
- 可用于：核心要义、误解纠正
- 我的理解：品格不是加分项，而是一道不可逾越的筛选门槛。

## 卡片 4：最有品格的人

- 原话：你可以选择你在“诚信标尺”上的位置。这并不是天生注定的，而是你可以自己做出的明确选择。而我人生中的英雄，都是我觉得在诚信方面表现卓越的人……我之所以敬佩他们，是因为我觉得他们是我这一生遇到过的最有品格的人。
- 来源：2003 年内布拉斯加大学林肯分校领导力课程演讲
- 文件：`buffett/interview/ba-fei-te-2003nian-nei-bu-la-si-jia-da-xue-lin-ken-fen-xiao-ling-dao-li-ke-cheng-yan-jiang.md`
- 可用于：定义、常见问题
- 我的理解：品格是可选择的，巴菲特敬佩英雄不是因为聪明或有钱，而是因为品格。

## 卡片 5：谨慎挑选你的英雄

- 原话：选择正确的“英雄”是极其重要的。你告诉我一个十岁孩子崇拜的偶像是谁，我大致就能预测他未来会成长成什么样的人。你一定要非常谨慎地挑选你的英雄，因为你迟早会在某些方面变得像他们。
- 来源：2003 年内布拉斯加大学林肯分校领导力课程演讲
- 文件：`buffett/interview/ba-fei-te-2003nian-nei-bu-la-si-jia-da-xue-lin-ken-fen-xiao-ling-dao-li-ke-cheng-yan-jiang.md`
- 可用于：思想演变、常见问题
- 我的理解：选英雄就是选成为谁，品格由榜样一点点塑造。

## 卡片 6：仰慕的人塑造你的世界观

- 原话：说到习惯，最好有恰当的“英雄”模范，我在这方面很幸运。你仰慕的人会塑造你的世界观和你对将来的期望。
- 来源：2007 年与比尔·盖茨对大学生的对话
- 文件：`buffett/interview/ba-fei-te-2007nian-11yue-he-bi-er-gai-ci-da-xue-sheng-dui-hua-shi-lu-jie-mu-fu-hao-mian-dui-mian.md`
- 可用于：核心要义、思想演变
- 我的理解：品格不是孤立养成的，崇拜什么样的人，就会长成什么样的人。

## 卡片 7：在逆境中展现品格

- 原话：我们对经营所罗门的人信心十足，过去他们帮助我们度过了困难得难以相信的日子，展现出他们的品格。
- 来源：1997 年伯克希尔股东大会
- 文件：`buffett/shareholders/1997nian-bo-ke-xi-er-gu-dong-da-hui.md`
- 可用于：代表案例、误解纠正
- 我的理解：品格平时看不真切，在压力和逆境中才最清楚。
