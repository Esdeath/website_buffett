# 巴菲特知识库勃艮第红主题色设计

日期：2026-07-18  
范围：站点强调色  
目标：让标题、链接和交互状态从深色正文中清晰突出，同时保留现有纸张式阅读体验。

## 1. 当前问题

站点使用 `#486b55` 作为绿色主题色。文章标题、二级标题、正文链接、侧栏状态和首页强调元素共用这套颜色。它在米白背景上可以正常阅读，但与深墨色正文的视觉距离偏小，正文中的链接不够醒目。

## 2. 配色方案

用户从三组预览中选择勃艮第红：

- 主强调色：`#842f3b`
- 浅强调色：`#f4e9e8`
- 页面背景：继续使用 `#f7f4ed`
- 面板背景：继续使用 `#fffdf8`
- 正文：继续使用 `#25302b`
- 次要文字：继续使用 `#6f756e`
- 引用线：继续使用 `#9b7a44`

主强调色在页面背景上的对比度为 `7.8:1`，满足 WCAG AAA 普通文字对比度要求。

## 3. 实现范围

在 `site/src/styles/tokens.css` 中把带有具体颜色含义的 `--green`、`--green-soft` 重命名为 `--accent`、`--accent-soft`。站点组件只引用语义变量，不直接重复主题色值。

以下界面元素使用 `--accent`：

- 文章一级标题和二级标题
- 普通链接和维基链接下划线
- 首页主按钮、栏目标题、卡片交互状态和键盘焦点轮廓
- 文章视图按钮
- 侧栏链接和当前项

以下界面元素使用 `--accent-soft`：

- 引用块背景
- 按钮悬停背景
- 侧栏悬停与当前项背景
- 首页的浅色强调区域

## 4. 保持不变

- 页面排版、字号、间距和布局
- 正文、次要文字和纸张背景色
- 金色引用线
- 知识图谱的分类配色
- Favicon 和其他品牌图片

## 5. 验收标准

- 标题和正文链接在米白背景上比当前绿色更醒目。
- 浅强调色只用于局部状态，页面不会出现大面积红色背景。
- 所有 `--green` 和 `--green-soft` 样式引用都迁移到新的语义变量。
- 桌面端与移动端没有文字溢出、遮挡或布局变化。
- 现有测试、内容验证和生产构建通过。
