# 致股东信与致合伙人信表格样式设计

日期：2026-07-20  
范围：致股东信、致合伙人信正文中的 Markdown 表格  
目标：采用用户选定的「年报式」方案，提高长财务表格的层级、对齐和扫读效率。

## 1. 当前问题

全站表格只设置了最大宽度和横向滚动。表头、数据行与正文使用相近的视觉处理，长表格缺少清晰的边界和行分隔；多位数字也不容易纵向比较。

## 2. 视觉方案

表格沿用现有纸张色、墨色和勃艮第红主题：

- 表格背景使用 `--panel`。
- 表头使用 `--accent-soft` 浅底和 `--accent` 文字。
- 表头下方增加 2px 勃艮第红分隔线。
- 表格外围使用细边框，数据行之间使用更浅的横线。
- 单元格增加稳定的横向和纵向内边距。
- 第一列左对齐，其余数据列右对齐；数字启用 `tabular-nums`，便于纵向比较。
- 鼠标经过数据行时显示轻微的浅红底色，不改变文字颜色。
- 表格不使用圆角、阴影或大面积深色背景。

## 3. 作用范围

`site/src/pages/sources/[group]/[slug].astro` 根据 `source.category` 判断页面类型，只给以下两个分类的正文 `<article>` 添加表格样式类：

- `致股东信`
- `致合伙人信`

样式选择器以该类为根节点。访谈与文章、股东大会、解读文章、注册表和其他 Markdown 表格保持现状。

## 4. 响应式行为

- 桌面端：表格填满正文栏；内容较少时保持整齐列宽。
- 窄屏和超宽表格：继续横向滚动，不压缩长标题或数字到不可读的宽度。
- 手机端：缩小单元格内边距，保留表头层级和数字对齐。
- 表头允许换行，单元格内容不与相邻列重叠。

## 5. 内容与结构

- 不修改 `buffett/` 下的 Markdown 原文。
- 不改变 Astro content collection、URL、SEO 或 Pagefind 数据。
- 保留 Markdown 生成的原生 `<table>`、`<thead>`、`<tbody>`、`<th>` 和 `<td>` 结构。
- 没有表格的信件页面不产生可见变化。

## 6. 验收标准

- 致股东信和致合伙人信中的表格呈现所选「年报式」外观。
- 表头、数据行和表格边界在现有纸张背景上清晰可辨。
- 第一列左对齐，其余列右对齐，数字纵向对齐稳定。
- 超宽表格在桌面和手机上可横向滚动，没有页面级横向溢出。
- 访谈与文章、股东大会和解读文章的表格样式不变。
- 桌面和手机截图检查通过。
- `npm test` 与 `npm run build` 通过。
