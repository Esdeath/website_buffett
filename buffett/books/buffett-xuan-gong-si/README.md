# 《巴菲特如何选择一家公司》编排说明

这是围绕公司选择与投资决策组织的原文全编。网站入口为 `/books/buffett-xuan-gong-si/`，完整书稿为同级目录中的 `../buffett-xuan-gong-si.md`。

## 内容与出处

- `outline.json`：八篇的阅读次序、二十四章的编者导读和编排说明。
- `evidence.json`：七个决策节点、十五则经核对的连续原文选录，以及延伸阅读章节。
- `coverage.json`：生成的正文覆盖清单，记录源文件及原文切片的 SHA256。

正文复用 `buffett-yuanwen` 的原文分节与主题编排，再按本书阅读次序组织。每个正文单元恰好出现一次，按原文件顺序拼回后须等于该文件的完整正文。原稿本身的译文、署名、提问、译注及省略一并保留；编者文字与原文标记分开。

2026 年阿贝尔来信集中收入末章补充资料。该文件正文标题中的作者有误，书中另加署名说明，不修改原稿，也不把它当作巴菲特讲话。

## 生成与校验

在 `site/` 中执行：

```sh
npm run build:decision-book
npm run check:decision-book
```

修改原文全编后，先生成其书稿，再生成本书。站点构建会检查两份交付稿是否与当前原稿和目录一致。校验从实际交付的 Markdown 中取回正文，比对原始范围、哈希与文字；不能通过只更新统计数字掩盖遗漏或改写。

## 阅读页

网站提供全书目录、七关决策树、逐关原文依据、章节目录与前后节导航。正文阅读页以当前书籍的顺序浏览；相同原文的检索和索引保留在原文主题全编，避免重复结果。

页面沿用知识库的三套主题与宋体阅读排版，以连续的判断问题、明确的三个分支和可展开原文作为结构。没有另加展示性动画；手机上分支纵向排列，原文与目录可用键盘展开。
